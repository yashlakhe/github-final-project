## Simple Interest Calculator

A simple Python application that calculates simple interest given principal, annual rate of interest, and time period in years.

### Formula
```
Simple Interest = (Principal * Time * Rate) / 100
```

### Input:
- `p`: Principal amount
- `t`: Time period in years
- `r`: Annual rate of interest

### Output:
- `simple interest`: Calculated simple interest amount

### Usage:
```bash
python simple-interest.py
```
